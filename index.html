Configura los Cursos para EE y las Unidades para CC

Los cursos definen el nivel educativo completo (ej: 1º ESO). Son fijos y no se pueden modificar. Las actividades EE van dirigidas a todas las clases del mismo nivel.

Las unidades definen grupos o aulas específicos (ej: 1ºA, 2ºB). Las actividades CC pueden dirigirse a una unidad concreta.
